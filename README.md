# ⚡ Shoeab Ahmed // Graphic Designer & Visual Strategist Portfolio

A modern, high-performance creative portfolio website built with **React 18**, **Tailwind CSS**, **Matter.js 2D Physics Engine**, **Lucide Icons**, and a zero-dependency **Web Audio SFX Synthesizer**.

---

## 🌟 Highlights & Features

- **Editorial Dark Aesthetic**: Deep minimal black background with subtle cyber-grid textures, electric neon green accents (\#00FF66\), and bold chunky typography.
- **Zero-Crop Artwork Preservation**: Every gig poster, campaign flyer, motion reel, and calendar spread sits inside dedicated museum-grade exhibit frames with \object-contain\ to preserve typography, line-ups, and margins.
- **Interactive Multi-Format Deliverable Dossier**: Modal viewer allowing live format switching (\Feed Post 1:1 / 4:5\, \Story / Reel 9:16\, \Cover Banner 16:9\, \Motion MP4\, and \Sunboard Spread\) with 1-click clipboard link sharing.
- **Clean Boolean Outlined Typography**: Integrated SVG mask knockout technique (\SvgOutlinedWord\) that eliminates interior overlapping stroke lines across tight-tracking display headers.
- **Matter.js 2D Physics Sandbox**: Interactive circular skill badges (\Illustrator\, \Photoshop\, \InDesign\, \Premiere Pro\, \After Effects\, \CorelDraw\, \Canva\, \Final Cut Pro\, etc.) reacting to mouse dragging, tossing, zero-gravity, gravity inversion, and explosion forces.
- **Multi-View Modes**: Switch instantly between **Bento Masonry Grid**, **Showcase Stream (16:10 / 4:3)**, and **Compact List View**.
- **Dynamic Asset Scanner & Upload API**: Backend Python \server.py\ featuring automatic media directory scanning, auto-categorization, deduplication, and \multipart/form-data\ custom upload endpoints.

---

## 🛠️ Tech Stack

- **Frontend**: React 18 (Babel standalone JSX), Tailwind CSS, Lucide Icons, Canvas Confetti.
- **Physics Engine**: Matter.js (2D rigid body dynamics).
- **Sound Design**: Native Web Audio API procedural oscillator synthesis.
- **Backend / Asset Server**: Python 3.x \ThreadingHTTPServer\ with CORS, Cache-Control, and REST upload endpoints.
